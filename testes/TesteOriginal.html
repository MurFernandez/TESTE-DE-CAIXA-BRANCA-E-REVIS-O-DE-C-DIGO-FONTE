Classe TesteOriginal

java.lang.Object

public class TesteOriginal
Suíte repetível de testes de caixa-branca para original/EstoqueArquivo.java. Executa os caminhos básicos do grafo de fluxo de controle (CFG) e demonstra objetivamente as falhas do legado.

Detalhes dos Métodos

main

public static void main(String[] args) throws IOException
Ponto de entrada da suíte de testes que executa todos os casos de teste (CT-01 a CT-11) e imprime o resumo consolidado no console.
Parâmetros:
args - argumentos de linha de comando (não utilizados)
Exceções Lançadas:
IOException - se ocorrer falha crítica ao manipular os arquivos temporários de teste

prepararAmbiente

private static void prepararAmbiente(String conteudoEstoque) throws IOException
Prepara os arquivos de ambiente antes da execução de cada caso de teste.
Parâmetros:
conteudoEstoque - conteúdo inicial a ser gravado em estoque.csv, ou null para simular arquivo ausente
Exceções Lançadas:
IOException - se ocorrer erro ao criar ou escrever no arquivo de estoque

limparArquivos

private static void limparArquivos()
Remove os arquivos temporários de estoque e movimentações utilizados durante os testes.

registrar

private static void registrar(String id, String descricao, boolean passou, String esperado, String observado)
Contabiliza e exibe o resultado formatado de um caso de teste no console.
Parâmetros:
id - identificador único do caso de teste (ex.: "CT-01")
descricao - descrição do cenário e caminho do CFG avaliado
passou - indica se o comportamento observado corresponde ao esperado
esperado - descrição do resultado esperado
observado - descrição do resultado obtido na execução
