public class TesteRevisado
Suíte repetível de testes de caixa-branca para revisado/EstoqueArquivo.java. Isola o ambiente recriando e removendo estoque.csv e movimentacoes.txt a cada caso de teste.

Ponto de entrada da suíte de testes que executa todos os casos de teste da versão revisada (CT-R01 a CT-R09), exibe o resumo no console e encerra com código de erro caso algum teste falhe.

registrar

private static void registrar(String id, String descricao, boolean passou, String detalhe)
Contabiliza a execução de um caso de teste e imprime seu resultado detalhado no console.
Parâmetros:
id - identificador único do caso de teste (ex.: "CT-R01")
descricao - resumo do cenário validado pelo caso de teste
passou - indica se todas as asserções do caso de teste foram satisfeitas
detalhe - valores observados durante a execução do teste
