public class EstoqueArquivo
Gerencia consultas e baixas de estoque persistidas em arquivos texto (CSV/TXT). Versão revisada com fechamento automático de recursos, validação de entradas, atualização consistente de saldo e tratamento explícito de falhas de I/O.

Detalhes dos Métodos

consultarQuantidade

public synchronized int consultarQuantidade(String codigo)
Consulta a quantidade disponível de um produto pelo seu código.
Parâmetros:
codigo - identificador do produto (não pode ser nulo ou em branco)
Retorno:
quantidade disponível em estoque, ou 0 caso o código não seja encontrado
Exceções Lançadas:
IllegalArgumentException - se o código for nulo ou vazio
UncheckedIOException - se o arquivo de estoque não existir ou falhar na leitura

registrarSaida

public synchronized boolean registrarSaida(String codigo, int quantidade)
Registra a saída (baixa) de uma quantidade de produto, abatendo o saldo no CSV e gravando o histórico no arquivo de movimentações com flush/close garantidos.
Parâmetros:
codigo - identificador do produto (não pode ser nulo ou em branco)
quantidade - quantidade a retirar (deve ser estritamente maior que zero)
Retorno:
true se houver saldo suficiente e a baixa for persistida; false se o saldo for insuficiente
Exceções Lançadas:
IllegalArgumentException - se o código for inválido ou se quantidade <= 0
UncheckedIOException - se ocorrer falha de leitura ou escrita nos arquivos

getUltimaMovimentacao

public synchronized String getUltimaMovimentacao()
Retorna o código do último produto que teve saída registrada com sucesso.
Retorno:
código do último produto movimentado, ou string vazia se nenhuma saída ocorreu

validarCodigo

private String validarCodigo(String codigo)
Valida e normaliza o código do produto removendo espaços nas extremidades.
Parâmetros:
codigo - código bruto informado na chamada
Retorno:
código validado e sem espaços extras
Exceções Lançadas:
IllegalArgumentException - se o código for nulo ou composto apenas por espaços
