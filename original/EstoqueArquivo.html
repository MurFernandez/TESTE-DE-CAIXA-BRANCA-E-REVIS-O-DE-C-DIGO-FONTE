Detalhes dos Métodos

consultarQuantidade

public int consultarQuantidade(String codigo)
Consulta a quantidade disponível de um produto no arquivo de estoque.
Parâmetros:
codigo - O código identificador do produto a ser buscado.
Retorno:
A quantidade disponível em estoque, ou 0 caso não seja encontrado ou ocorra erro de leitura.

registrarSaida

public boolean registrarSaida(String codigo, int quantidade)
Registra a saída de uma determinada quantidade de um produto, caso haja saldo disponível.
Parâmetros:
codigo - O código identificador do produto.
quantidade - A quantidade a ser retirada do estoque.
Retorno:
true se a saída foi registrada com sucesso; false caso contrário.

getUltimaMovimentacao

public String getUltimaMovimentacao()
Retorna o código do último produto que teve saída registrada.
Retorno:
O código da última movimentação ou uma string vazia caso nenhuma tenha ocorrido.
